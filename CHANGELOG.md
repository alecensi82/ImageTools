# Novità di ImageTools

## 1.1
- Nuova icona
- Controllo degli aggiornamenti automatico e manuale da GitHub (menu ImageTools › Controlla aggiornamenti…)
- Con «Sovrascrivi originali» un file convertito non prende più il posto di un'altra immagine (es. foto.png → foto_png.jpg accanto a foto.jpg)
- «Ancora» lavora solo sui file già elaborati e non tocca più gli originali dopo un annullamento
- App firmata e notarizzata da Apple
